📘 Project Details – Library Management System (Java + MySQL)

The Library Management System is a desktop-based application developed using Java Swing for the user interface and MySQL as the backend database.
This project helps automate daily library operations such as managing books, students, staff, issuing and returning books, and maintaining records.
The system provides a simple, user-friendly dashboard, allowing the librarian or admin to access all modules easily.

🎯 Project Objectives

To digitalize manual library activities.
To provide an efficient way to manage books, students, and staff.
To reduce paperwork and human errors.
To maintain accurate records of issued and returned books.
To ensure fast retrieval of library information.

🖥️ Dashboard Overview
The main dashboard contains buttons for all library modules:

📚 Books Management
Books Available – View complete list of books in the library.
Add Books – Add new books to the library.
Remove Books – Delete books from the system.

👨‍🏫 Staff Management
Staff Details – View existing staff records.
Add Staff – Add new staff members.
Remove Staff – Remove staff from the system.

🎓 Student Management
New Student – Register a new student.
Student Details – View list of registered students.

🔐 Admin Management
Edit Admin – Update admin credentials and information.

📖 Circulation (Issue/Return)
Issue Book – Issue a book to a student.
Return Book – Return an issued book and update availability.

📊 Reports & Statistics
Statistics – View graphical/statistical reports such as:
Total books
Issued books
Returned books
Available books
Number of students/staff
